Settings

Each cap limits that source's share of the summed CCL/DCL and sets its over-current guard limit (with the battery's own limit, whichever is lower).

Always on, not settable: frame timeouts 5 s (1 Hz frames) and 6 s (Blue Nova pack 2), the alarm trip, plausibility checks, the start-up hold, the over-current guard, the watchdog and silence during OTA. In fail-safe, CVL never goes below and DVL never above the last good pack voltage.

Inverter transmit (port INV)

Off by default. Turning it on asks for a typed confirmation. Port INV then runs in normal, one-shot mode and sends only 0x351, 0x355, 0x356, 0x359, 0x35C and 0x35E (fixed lengths), at most once a second each. The start-up hold (CCL = DCL = 0) applies until every enabled source has been valid for the hold time. Disabling port INV or changing its bitrate turns transmit off. Port A never transmits.

Transmit to the inverter?

The gateway will start talking to the inverter on port INV as the battery. The inverter will charge and discharge using the limits shown on this page.

  • Check the fail-safe CVL/DVL and the CCL/DCL maximums first: they are what the inverter gets whenever a source is missing.
  • Only one device may act as the battery on that bus: disconnect the battery's own link to the inverter.
  • Port A stays listen-only; port B never sends data frames.

CAN tap

Port A (MCP2515 #2) in listen-only mode: the gateway never transmits, acknowledges or sends error frames on this bus.

Map INT pins (bench only)

Finds which GPIO each module's INT line is really wired to. Each module in turn listens alone (listen-only, all IDs) until a test frame with an ID in 0x100–0x1FF arrives, then every candidate GPIO is sampled; this repeats 5 times. Nothing is transmitted by the device. Bench only: the frames must come from tools/bench_can_check.py --bench --tests 4 on a bus with no battery or inverter (the script starts the mapping itself, or keeps sending while this button's run is going). pins.h is never changed. Up to about 20 s per module; the tap pauses meanwhile. Serial console: intmap.

Ports

Each port has its own bitrate, applied at once (no reboot). Port A is always listen-only. Port INV is listen-only unless inverter transmit is turned on (Aggregator page). Port B is listen-only unless Acknowledge on B is ticked: then it acknowledges the KNY's frames (needed when nothing else on that bus does) but never sends a data frame; if it causes bus errors (wrong bitrate) it drops back to listen-only by itself. 1 Mbit/s is not possible with the 8 MHz crystal.
